Use case: ui-mockup
Asset type: high-fidelity desktop WebUI design concept for an AstrBot plugin

Primary request:
Create a polished, production-ready LIGHT THEME desktop administration interface for a Bot humanization plugin named "Humanize". The interface should feel subtly cute, calm, restrained, and slightly distant. It must be a practical operations console, not a landing page and not concept art.

Canvas and framing:
- 16:9 landscape, full browser viewport screenshot, straight-on view.
- Show only the application interface. No laptop frame, phone frame, desk scene, perspective tilt, or presentation board.
- Dense but breathable desktop layout suitable for repeated daily use.

Visual direction:
- Entire interface is light theme only.
- Main background: warm near-white #FCFAFB.
- Sidebar and top bar: white or extremely pale blush #FFF8FB.
- Primary accent: dusty soft pink #C98FA8.
- Selected states: pale blush #F7E8EF.
- Borders: cool pale gray-pink #E8E0E4.
- Text: muted neutral gray #4C4549, with darker gray only where necessary for readability.
- Small status accents may use muted sage green and pale amber.
- Cute feeling comes only from a tiny friendly abstract Bot face mark, soft pink active states, refined line icons, compact controls, and gentle spacing.
- Use crisp sans-serif typography, 6px corner radius or less, hairline borders, almost no shadow.
- Use familiar Lucide-style outline icons in tool buttons.

Layout:
1. A 216px light sidebar with a small abstract Bot face mark and the word "Humanize". Navigation items, in this order: "学习总览", "黑话词库", "证据与推断", "协议监控", "规则与人格", "关系记忆", "设置". Select "黑话词库" using a pale pink background and a slim dusty-pink left indicator. Show a subtle "规划中" badge beside "关系记忆".
2. A white top bar. Left side title: "黑话词库". Beside it show scope selector "QQ群 · 赛博茶话会". Right side contains a compact search field, an icon-only export button, a light pink "学习中" toggle, and a small administrator avatar.
3. Main content begins with four compact metrics in one row: "已学习 128", "待确认 12", "协议成功率 98.7%", "本周拦截 9". Keep these as restrained bordered metric blocks, not colorful cards.
4. Main left area is a professional data table titled "最近词条". Include compact search and filters for "状态" and "作用域". Columns: "状态", "词条", "推测含义", "作用域", "置信度", "出现次数", "最近出现". Example rows: "开香槟 / 提前庆祝成功 / 待确认 / 72%", "上桌 / 获得参与资格 / 已确认 / 94%", "红温 / 情绪激动或恼怒 / 有歧义 / 61%". Use small quiet status chips and icon-only row actions.
5. A right-side detail panel for the selected term "开香槟". Show inferred meaning, confidence 72%, scope "本群", occurrence count 3, a short evidence timeline with two message excerpts, and restrained buttons "确认释义" and "拒绝". The panel should feel integrated into the page, not like a floating card.
6. Bottom full-width protocol strip titled "XML 协议状态" with a tiny success-rate line chart and three recent rows: Reply success, No Reply success, and one blocked malformed response labeled "缺少 </Reply>".
7. Include a small read-only "默认规则" summary near the detail panel: enabled, administrator configured, single message limit "10 字", maximum "12 条".

Interaction and hierarchy constraints:
- Clearly communicate why a term was learned, how it was interpreted, and when it was injected.
- Current QQ group scope must remain visible to prevent cross-group confusion.
- Experimental future features should be marked "规划中" rather than presented as complete.
- Text must fit inside controls without overlap.
- Stable dimensions, aligned grid, professional spacing, no nested cards.

Avoid:
- Absolutely no dark theme, dark sidebar, dark header, black panel, navy panel, or dark code editor.
- No gradients, glassmorphism, glowing effects, bokeh, decorative blobs, large shadows, or translucent floating layers.
- No hearts, stars, flowers, bows, stickers, sparkles, kawaii character illustration, oversized mascot, or childish decoration.
- No purple-blue palette, saturated hot pink, candy colors, or monochrome pink overload.
- No oversized pills, huge headings, marketing hero, landing-page composition, stock illustration, or device mockup.
- No excessive cards and no cards inside cards.
- No watermark, no unrelated logos, no random English filler, no illegible placeholder text.

Output intent:
A realistic, shippable WebUI screenshot that balances a gentle pale-pink cute identity with a quiet, restrained, professional administration experience.
